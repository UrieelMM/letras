# Textos bíblicos incluidos

Los archivos de este directorio se generan con `scripts/ingest-bible.mjs` y se
sirven por libro para permitir carga perezosa y caché offline en IndexedDB.

- `rv1909`: Reina-Valera 1909, texto de dominio público. La fuente de ingesta
  es el módulo público de Wikisource distribuido por GetBible v2.
- `kjv`: King James Version 1769, conjunto de datos de dominio público de
  `farskipper/kjv`, publicado bajo Unlicense.
- `lbla`: La Biblia de las Américas, importada del conjunto de datos de
  `mrk214/bible-data-es-spa`. Copyright 1986, 1995, 1997 de The Lockman
  Foundation; consultar el manifiesto antes de redistribuirla.
- `nbla`: Nueva Biblia de las Américas, The Lockman Foundation.
- `ntv`: Nueva Traducción Viviente, Tyndale House Publishers.
- `nvi`: Nueva Versión Internacional, Biblica, Inc.
- `rvr1960`: Biblia Reina-Valera 1960, Sociedades Bíblicas Unidas.
- `tla`: Traducción en Lenguaje Actual, Sociedades Bíblicas Unidas.

Los manifiestos de cada versión conservan la fuente, editorial y declaración
legal que acompañaban al conjunto de datos descargado. Consulta sus términos
antes de redistribuir cualquier traducción con copyright.
